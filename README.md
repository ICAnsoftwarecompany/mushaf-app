# تطبيق المصحف

مصحف للموبايل (أندرويد و iOS) مبني بـ Expo و React Native: رواية حفص عن عاصم، بترتيب صفحات مصحف المدينة النبوية (604 صفحة)، ويشتغل بالكامل من غير إنترنت.

## البداية

```bash
npm install
npx expo start --clear
```
