# الهوية: «يتلو»

## الاسم

**يتلو — Yatlu**، من قوله تعالى في سورة البينة (آية ٢):
«رَسُولٌ مِّنَ ٱللَّهِ يَتْلُوا صُحُفًا مُّطَهَّرَةً».

الاسم بيظهر بالمعنى ده في **الشاشة الافتتاحية** كل مرة التطبيق يفتح. نص الآية بييجي من `ayahs.json` زي ما هو (القاعدة 1)، عن طريق `NAME_AYAH_TEXT` في `src/constants/brand.ts`.

| الاسم بالإنجليزي | Yatlu |

## اللوجو

![معاينة اللوجو](brand-preview.png)

**الفكرة:** اللوجو هو الاسم نفسه «يَتْلُو» مكتوب **بخط الرقعة** بالتشكيل، بلون دهبي متدرج على خلفية خضرا، وتحته خط رفيع في نصه نجمة ثمانية صغيرة (زي علامة الحزب ۞ في المصحف). خط الرقعة واضح جدًا حتى في المقاسات الصغيرة.

- **الخط:** Aref Ruqaa Bold، رخصته SIL Open Font License، وبتسمح باستخدامه في اللوجوهات.
- **الحروف متحوّلة لمسارات (outlines)** جوه ملفات الـ SVG، فاللوجو مش محتاج الخط يكون متسطّب علشان يظهر.

| الملف | الاستخدام |
|---|---|
| `assets/brand/yatlu-icon.svg` | الأيقونة كاملة بخلفية مربعة (المصدر الأساسي) |
| `assets/brand/yatlu-icon-rounded.svg` | نفس الأيقونة بحواف دائرية (للعرض والمواقع) |
| `assets/brand/yatlu-wordmark.svg` | الاسم لوحده بخلفية شفافة (الشاشة الافتتاحية، المطبوعات) |
| `assets/brand/yatlu-monochrome.svg` | نسخة بيضا بلون واحد (أيقونات أندرويد 13 المتلونة) |

الصور اللي التطبيق بيستخدمها متولّدة من ملفات الـ SVG دي:

| الملف | المقاس | الاستخدام |
|---|---|---|
| `assets/images/icon.png` | 1024 | أيقونة iOS والأيقونة العامة |
| `assets/images/android-icon-foreground.png` | 1024 | أيقونة أندرويد (المقدمة، جوه المنطقة الآمنة) |
| `assets/images/android-icon-background.png` | 1024 | أيقونة أندرويد (الخلفية الخضرا) |
| `assets/images/android-icon-monochrome.png` | 1024 | أيقونة أندرويد بلون واحد |
| `assets/images/splash-icon.png` | 512 | شاشة البداية والشاشة الافتتاحية |
| `assets/images/favicon.png` | 196 | أيقونة المتصفح |
| `public/icon-192.png`، `public/icon-512.png` | 192، 512 | أيقونات PWA |

### تعديل اللوجو

الـ SVG بيتولّد بسكربت في `scripts/brand/` (بيشكّل الحروف العربية بـ HarfBuzz ويحوّلها لمسارات):

```bash
pip install fonttools uharfbuzz
cd scripts/brand
npm pack @expo-google-fonts/aref-ruqaa && tar xzf expo-google-fonts-aref-ruqaa-*.tgz
python3 compose.py
```

لتغيير الخط أو النص أو الزخرفة، عدّل `FONT` و `TEXT` و `ornament()` في `compose.py`. بعدها حوّل الـ SVG لـ PNG بنفس المقاسات اللي في الجدول.

**بدائل اتجربت:** خط النسخ (Amiri Bold) وخط النستعليق (Noto Nastaliq Urdu Bold). اتختار خط الرقعة لأنه الأوضح في المقاسات الصغيرة.

## الألوان

ألوان هادية: أخضر غامق مريح، ودهبي ناعم، وكريمي.

| الاسم | اللون | الاستخدام |
|---|---|---|
| أخضر | `#1F463D` | خلفية شاشة البداية والشاشة الافتتاحية وأيقونة أندرويد |
| أخضر فاتح | `#2E6153` | أعلى تدرج خلفية الأيقونة |
| أخضر غامق | `#1A3D35` | أسفل تدرج خلفية الأيقونة |
| دهبي | `#C9A86A` | مرجع الآية والزخرفة |
| دهبي فاتح | `#F0D9A6` → `#B8925A` | تدرج حروف الاسم في اللوجو |
| كريمي | `#F6EEDC` | نص الآية في الشاشة الافتتاحية |

الألوان دي في `src/constants/brand.ts` (`Brand.colors`). **ألوان القراءة نفسها** منفصلة وبتتغير مع الثيم ([themes.md](themes.md)).

- بتشتغل على أندرويد و iOS والويب.
