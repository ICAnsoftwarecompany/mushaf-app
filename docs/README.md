## نظرة سريعة

- **التطبيق:** «يتلو» — مصحف مبني بـ Expo و React Native، بيطلع منه **3 نسخ** من نفس الكود: ويب (PWA بيشتغل أوفلاين) وأندرويد و iOS.
- **المصحف:** رواية حفص عن عاصم، بترتيب صفحات مصحف المدينة النبوية (604 صفحة، 15 سطر).
- **لغتين:** عربي وإنجليزي (الواجهة كلها)، والقرآن والأذكار عربي دايمًا.
- **أوفلاين بالكامل:** النص، والتجويد، والتفسير، والترجمة، والأذكار، ومواقيت الصلاة، والقبلة — ومفيش باك إند. التلاوة بس محتاجة نت أول مرة (أو تحميل).
- **التابات:** المصحف، المواقيت، الأذكار، البحث، الإعدادات. والقارئ فيه وضع صفحات ووضع نص متصل وصفحتين على الشاشات العريضة.

## أوامر سريعة

```bash
npm install                 # تثبيت المكتبات
npx expo start --clear      # تشغيل المشروع
npx tsc --noEmit            # فحص TypeScript
npx expo lint               # الـ lint
npm test                    # اختبارات البيانات
npm run build:quran-data    # إعادة بناء بيانات المصحف من المصادر والتحقق منها
npm run build:extra-data    # الأذكار، المدن، التجويد، التفسير، الترجمة
npm run build:web           # بناء نسخة الويب في dist/
npx eas-cli@latest build --platform android --profile preview   # APK للتجربة
```
