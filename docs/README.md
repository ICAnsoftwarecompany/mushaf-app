## نظرة سريعة

- **التطبيق:** مصحف للموبايل (أندرويد و iOS) مبني بـ Expo و React Native، وبيشتغل كمان على الويب للمعاينة.
- **المصحف:** رواية حفص عن عاصم، بترتيب صفحات مصحف المدينة النبوية (604 صفحة، 15 سطر).
- **أوفلاين بالكامل:** النص والصفحات والفهرس والبحث كلهم جوه التطبيق، ومفيش باك إند.
- **الشاشات الحالية:** الفهرس (السور والأجزاء)، القارئ، البحث، العلامات، الإعدادات.

## أوامر سريعة

```bash
npm install                 # تثبيت المكتبات
npx expo start --clear      # تشغيل المشروع
npx tsc --noEmit            # فحص TypeScript
npm run build:quran-data    # إعادة بناء بيانات المصحف من المصادر والتحقق منها
```
