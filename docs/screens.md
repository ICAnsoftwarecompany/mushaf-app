# الشاشات

## خريطة التنقل

```
(tabs)
├── /             الفهرس
├── /search       البحث
├── /bookmarks    العلامات
└── /settings     الإعدادات

/mushaf/[page]?ayah=<رقم الآية العام>    القارئ (بيفتح فوق التابات)
```

**رقم الآية العام** هو ترقيم من 1 لـ 6236 لكل آيات المصحف بالترتيب. مثلًا آية الكرسي (البقرة 255) رقمها 262. الدوال `surahOfAyah()` و `ayahNumber()` و `pageOfAyah()` في `src/data/quran/index.ts` بتحوّل بينه وبين السورة والآية والصفحة.

فتح صفحة من أي مكان:

```ts
router.push({ pathname: '/mushaf/[page]', params: { page: '50' } });
router.push({ pathname: '/mushaf/[page]', params: { page: '42', ayah: '262' } }); // مع تحديد آية
```

## الفهرس — `src/app/(tabs)/index.tsx`

- العنوان «يتلو»، وتحته «المصحف الشريف · رواية حفص عن عاصم · مصحف المدينة».

- كارت **متابعة القراءة** بيظهر لو فيه آخر صفحة محفوظة، وبيفتحها على طول.
- مفتاح بين **السور** (114) و **الأجزاء** (30).
- كل سورة فيها: رقمها، اسمها، مكية أو مدنية، عدد الآيات، ورقم صفحة البداية.
- كل جزء فيه: اسمه، والسورة والآية اللي بيبدأ منها، ورقم الصفحة.

## القارئ — `src/app/mushaf/[page].tsx`

- بيعرض الصفحات بنفس ترتيب سطور مصحف المدينة (15 سطر)، مع عنوان السورة والبسملة في أماكنهم.
- **التقليب:** سحب يمين وشمال على الموبايل بقائمة أفقية بتقف عند كل صفحة (`FlatList`)، والصفحة الجاية على الشمال، سواء الموبايل لغته عربي أو إنجليزي. على الويب فيه أزرار في الركنين، وأسهم الكيبورد (السهم الشمال = الصفحة الجاية).
- **هامش الصفحة:** اسم السورة على اليمين، والجزء على الشمال، ورقم الصفحة تحت.
- **شريط الأدوات:** بيظهر أول ما الشاشة تفتح ويختفي بعد ثانيتين ونص. ضغطة على أي مكان فاضي في الصفحة بتظهره أو تخفيه. فيه: رجوع، واسم السورة والجزء والصفحة، و«علامة» لحفظ الصفحة.
- **تحديد آية:** ضغطة على أي كلمة بتحدد الآية كلها وتظهر شريط تحتاني فيه: «علامة» لحفظ الآية، و«مشاركة» (موبايل بس)، و«إغلاق».
- **آخر قراءة:** بتتحفظ تلقائيًا مع كل تقليب.
- **حجم الخط:** بيتحسب لكل صفحة بقياس العرض الحقيقي لكل سطر، علشان أطول سطر ييجي على عرض الشاشة. السطور الكاملة بتتوزع على العرض، والسطور القصيرة (زي آخر سورة) بتتوسّط.
- صفحة 1 و 2 (الفاتحة وأول البقرة) بيتعرضوا في نص الصفحة زي المصحف الورقي.
