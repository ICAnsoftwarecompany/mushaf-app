# الثيمات والألوان

## الثيمات الحالية

التعريف في `src/theme/theme.ts`.

| المعرّف | الاسم | الخلفية | النص | اللون المميز | غامق؟ |
|---|---|---|---|---|---|
| `classic` | كلاسيك (الافتراضي في الوضع الفاتح) | `#FDF6E3` | `#2B2B2B` | `#B08D57` | لا |
| `white` | أبيض | `#FAFAF7` | `#1F1F1F` | `#2E7D5B` | لا |
| `sepia` | سيبيا | `#F1E7D0` | `#3B2F24` | `#8B5E34` | لا |
| `mint` | أخضر هادي | `#EEF5EE` | `#1E2B22` | `#3E7D57` | لا |
| `night` | ليلي (الافتراضي في الوضع الغامق) | `#1A1A1A` | `#E6E0D4` | `#C9A86A` | نعم |
| `navy` | كحلي | `#141B26` | `#E3E6EC` | `#D2B57A` | نعم |
| `oled` | أسود (OLED) | `#000000` | `#D9D4C7` | `#A88B55` | نعم |

**الاختيار الافتراضي** هو `system`: بيستخدم `classic` لو الموبايل على الوضع الفاتح، و `night` لو على الغامق.

## مفاتيح الألوان

| المفتاح | الاستخدام |
|---|---|
| `background` | خلفية الصفحة والشاشات |
| `surface` | الكروت، والأشرطة، وإطار عنوان السورة |
| `text` | نص الآيات والعناوين |
| `textSecondary` | النصوص الثانوية وهامش الصفحة |
| `accent` | علامات نهاية الآيات، والعناوين المميزة، والأزرار |
| `accentSoft` | علامات الأجزاء والأحزاب (لاحقًا) |
| `highlight` | تظليل الآية المختارة، والضغط على العناصر |
| `border` | الفواصل والحدود |
| `statusBar` | لون أيقونات شريط الحالة (`dark-content` / `light-content`) |

وكمان `tajweed`: ألوان التجويد (المد، والغنة، والتفخيم، والحروف التي لا تُنطق)، بنسخة للثيمات الفاتحة ونسخة للغامقة.

## الاستخدام في الكود

```tsx
// الطريقة الكاملة
const { theme, mode, setMode } = useMushafTheme();
<View style={{ backgroundColor: theme.colors.background }} />

// الطريقة المختصرة (بتستخدمها ThemedText و ThemedView والتابات)
const colors = useTheme(); // text, background, backgroundElement, backgroundSelected, textSecondary, accent
```

## إضافة ثيم جديد

1. ضيف المعرّف في `ThemeId` في `src/theme/theme.ts`.
2. ضيف الثيم في `themes` بنفس المفاتيح بالظبط.
3. اتأكد إن التباين بين النص والخلفية **7:1 أو أكتر**، علشان القراءة الطويلة.
4. الثيم هيظهر لوحده في شاشة الإعدادات.
5. حدّث الجدول اللي فوق و [changelog.md](changelog.md).

## إرشادات

- متستخدمش أبيض صافي على أسود صافي، ولا العكس، للنص الطويل.
- الوضع الغامق: نص كريمي فاتح بدل الأبيض الصافي.
- علامات نهاية الآيات وعناوين السور بلون `accent`، علشان تبان من غير ما تشتت.

## الوضع الليلي بالمواقيت

لو «الوضع الليلي بعد المغرب» مفعّل في الإعدادات والمدينة متحددة، `ThemeContext` بيحسب كل دقيقة: من المغرب للفجر الثيم الغامق، وغير كده الفاتح (بيتجاهل الثيم المختار وقتها).
