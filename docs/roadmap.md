## المرحلة 3 — الإعدادات الكاملة ✅ (2026-10-06)

شاشة الإعدادات مقسّمة لأقسام. كل الإعدادات بتتحفظ على الجهاز، وكلها بتشتغل أوفلاين.

### عام
- [x] **اللغة:** عربي / English (ترجمة كل نصوص الواجهة، والاتجاه بيتظبط حسب اللغة)
- [x] **حجم خط الواجهة:** − / + (مثلًا من 1 لـ 10)
- [x] **وزن خط الواجهة:** عادي / عريض
- [x] **الثيم:** 7 ثيمات (موجود)
- [x] **تلقائي فاتح/غامق حسب الموبايل** (موجود كخيار «تلقائي»)
- [x] **الوضع الليلي التلقائي بالوقت:** يتحول للغامق بعد المغرب وللفاتح بعد الفجر (بيستخدم مواقيت الصلاة)
- [x] **إبقاء الشاشة منورة** أثناء القراءة (`expo-keep-awake`)
- [x] **الاهتزاز** عند الضغط
- [x] **إظهار/إخفاء الشاشة الافتتاحية**

### إعدادات المصحف
- [x] **معاينة حية** للبسملة بالإعدادات المختارة (زي الصورة)
- [x] **حجم خط المصحف:** − / + (تكبير للصفحة كلها مع الحفاظ على ترتيب السطور، أو وضع «نص متصل» بخط أكبر)
- [x] **وزن خط المصحف:** رفيع / عريض
- [x] **وضع العرض:** صفحات المصحف / نص متصل (آية تحت آية)
- [x] **ألوان التجويد:** تشغيل/إيقاف (المفتاح موجود، والعرض لسه)
- [x] **إظهار/إخفاء** هامش الصفحة (اسم السورة والجزء ورقم الصفحة)
- [x] **القارئ الافتراضي** للتلاوة (مع المرحلة 5)

### إعدادات الأذان ومواقيت الصلاة
- [x] **المذهب** (لحساب العصر): شافعي (الجمهور) / حنفي
- [x] **طريقة الحساب:** الهيئة المصرية، رابطة العالم الإسلامي، أم القرى، ISNA، كراتشي، الخليج، الكويت، قطر، سنغافورة، تركيا، طهران… (مكتبة `adhan` بتحسبها أوفلاين)
- [x] **حساب تلقائي:** اختيار طريقة الحساب حسب البلد تلقائيًا
- [x] **التوقيت الصيفي:** تشغيل/إيقاف (+ ساعة)
- [x] **تعديل يدوي** لكل صلاة بالدقايق (−/+)
- [x] **المدينة:** عرض المدينة الحالية + زرار «تغيير المدينة» (قايمة مدن جوه التطبيق علشان تشتغل أوفلاين)
- [x] **تحديد الموقع تلقائيًا:** بالـ GPS (`expo-location`)، مع خيار استخدام الإنترنت لمعرفة اسم المدينة
